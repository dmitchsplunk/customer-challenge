# Five questions, in plain words

Ask only what the description didn't already answer. One at a time.

1. "What kind of company is this, and what does the agent do, for whom?"
   Example answer: "A regional credit union. A member support assistant that answers questions about accounts and cards."
2. "Which systems does it read or write? Up to four."
   Example: "Account lookup, card controls, help articles, a case system."
3. "Which of these worries them most?"
   - leaks personal data  → pii_leak
   - makes things up      → fabricated_citation
   - picks the wrong tool → wrong_tool
   - follows a malicious instruction → injection_success
   - is too slow          → latency
4. "Who'll be in the room, and what does each person care about?"
5. "Anything they said they want to see, in their own words?"

If they don't know an answer, write UNANSWERED and move on. Never guess the stack.
